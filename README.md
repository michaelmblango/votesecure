## Project Description
VoteSecure is a secure, web-based institutional voting platform that allows
eligible voters to authenticate, cast ballots exactly once, and enables
administrators to manage elections and generate transparent results.

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React.js + Tailwind CSS |
| Backend | Python + FastAPI |
| Database | PostgreSQL |
| Cache/OTP | Redis |
| Auth | bcrypt + JWT |
